This repo's demos are dart2js/dart2wasm, not Flutter, so nothing in the corpus can reach it — example/web/web/index.html:425 documents it for consumers and no Dart file calls it.
emitChildEvent     # Reached only through SandboxExtension, at sandbox.dart:696 `parent?.emitChildEvent(...)`, where `parent` arrives via HostContext. test/src/bridge/monty_runtime_child_events_test.dart calls it DIRECTLY on a runtime, which proves the method works but not that the sandbox path wires it. Closing this needs a spawn-a-child integration test that asserts BridgeChildEvent on the parent's `events` stream.
