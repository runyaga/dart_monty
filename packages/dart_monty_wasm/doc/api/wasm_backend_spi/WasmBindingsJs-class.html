WasmBindingsJs

WasmBindingsJs class

VM stub for WasmBindingsJs.

On non-web platforms dart:js_interop is unavailable, so this stub provides the same class name so that the conditional import in monty_wasm.dart compiles. The constructor throws immediately — tests always inject a mock, so this path is never reached.
