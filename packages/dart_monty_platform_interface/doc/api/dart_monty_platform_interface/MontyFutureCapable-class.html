MontyFutureCapable

MontyFutureCapable class abstract

Interface for platforms that support async/futures execution.

Platforms implement this to advertise futures capability. Callers check platform is MontyFutureCapable before invoking these methods, avoiding UnsupportedError on platforms where the upstream runtime does not expose the futures state machine.

See also:

  • MontyPlatform — the core platform contract
  • MontySnapshotCapable — companion interface for snapshot/restore
