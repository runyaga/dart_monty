MontyPlatform get instance

The current platform instance.

Defaults to null until set by a platform implementation. Throws StateError if accessed before being set.

Deprecated: Instantiate platform implementations directly instead of relying on a global singleton. Pass the platform explicitly to consumers (e.g. DefaultMontyBridge(platform: myPlatform)).

Implementation
