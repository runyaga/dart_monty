MontySessionManager

MontySessionManager class

Manages the lifecycle of McpMontySession instances.

Tracks named sessions, handles creation/destruction, and provides stateless execution (creates a temporary platform per call).

Host functions registered via registerHostFunction are propagated to all newly created sessions and used in stateless execution.
