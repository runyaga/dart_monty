McpMontySession

McpMontySession class

A persistent Python interpreter session for MCP.

Wraps a MontyPlatform in a MontySession to persist Python globals across calls. Serializes concurrent requests with a simple lock so two MCP tool calls to the same session don't corrupt state (blocker B3).

Registered HostFunctions are callable from Python code via the MontySession.start() dispatch loop.
