Creates a fresh instance of this plugin for a child sandbox.

Override to opt into automatic child inheritance via SandboxPlugin. Return null (the default) to exclude this plugin from children.

The returned instance must be independent — it will be registered on a separate MontyBridge and disposed with the child.

context carries the child's ID and optional per-child working directory. Plugins that need filesystem isolation (e.g., FsPlugin) can use ChildSpawnContext.workingDirectory to create a private directory for the child.
