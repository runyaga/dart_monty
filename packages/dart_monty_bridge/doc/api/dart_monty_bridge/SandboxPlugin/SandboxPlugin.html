Creates a SandboxPlugin.

platformFactory creates a fresh MontyPlatform for each child. childPluginRegistryFactory optionally provides plugins to children. When null, children automatically inherit plugins from parentPlugins that return non-null from MontyPlugin.createChildInstance. parentPlugins the parent registry's plugin list -- used for automatic child inheritance when childPluginRegistryFactory is null. maxChildren limits concurrent children (default: 16). maxDepth limits recursion depth if children also have SandboxPlugin (default: 3). Set currentDepth when creating nested plugins. childLimits sets resource limits for child interpreters.
