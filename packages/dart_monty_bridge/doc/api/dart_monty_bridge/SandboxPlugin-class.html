SandboxPlugin

SandboxPlugin class

Plugin that spawns Python scripts in separate Monty interpreter instances.

Each child gets its own MontyPlatform (via platformFactory) and DefaultMontyBridge. The parent Python script can spawn children with sandbox_spawn(code) and await their results with sandbox_await(handle).

Children are sandboxed: each has its own interpreter state. All living children are killed when this plugin is disposed.
