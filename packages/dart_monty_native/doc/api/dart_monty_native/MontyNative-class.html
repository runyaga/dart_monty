MontyNative

MontyNative class

Native Isolate implementation of MontyPlatform.

Uses a NativeIsolateBindings abstraction to call into a background Isolate that runs the native FFI. Manages a state machine: idle -> active -> disposed.

final monty = MontyNative();
await monty.initialize();
final result = await monty.run('2 + 2');
print(result.value); // 4
await monty.dispose();
